Model approach

Machine learning made interpretable for public risk awareness

AlzAware uses demographic information, education, medication count, and self-reported medical history to generate a model-based reference score.

The score is designed to support triage and awareness, not to replace clinical cognitive testing.

Model pipeline

Input features

Questionnaire and health-history variables.

XGBoost model

Trained on processed matrix data with one-hot encoded predictors.

Reference output

Score compared with AD and non-AD groups.

Output design

The score is useful because it is contextualized

The final user-facing output avoids unsupported diagnostic language. It explains that a higher score means higher model-estimated risk, then compares the user’s score with people in the AD and non-AD reference groups.

“Higher score means more model-estimated risk of AD. In a large reference dataset, xx% of AD participants and yy% of non-AD participants had scores higher than yours.”
