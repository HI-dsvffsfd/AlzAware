Model approach

Machine learning made interpretable for public risk awareness

AlzAware uses demographic information, education, medication count, and self-reported medical history to generate a model-based reference score.

The score is designed to support triage and awareness, not to replace clinical cognitive testing.

Model pipeline

Input features

Questionnaire and health-history variables.

XGBoost model

Trained on processed matrix data with one-hot encoded predictors.

Reference output

Score compared with AD and non-AD groups.

Technical foundation

Two model versions for comparison

The project evaluates both a full model with cognitive game variables and a questionnaire-only model without game variables. This helps determine whether short digital cognitive tasks add meaningful predictive value.

With-game model

Uses 26 original predictors, including reaction-time and memory-game performance variables after preprocessing.

Without-game model

Uses 24 original predictors and supports a simpler assessment flow when game data is unavailable.

Evaluation

Why AUC matters more than raw accuracy

Alzheimer’s datasets often contain many more non-AD observations than AD observations. In this setting, raw accuracy can look high even when a model misses many AD cases.

AlzAware therefore emphasizes ROC-AUC and reference-score behavior, which better measure how well the model separates higher-risk and lower-risk individuals.

Primary reporting metrics

ROC-AUC for discrimination, train/test comparison for generalization, and score distribution analysis for interpretability.

Output design

The score is useful because it is contextualized

The final user-facing output avoids unsupported diagnostic language. It explains that a higher score means higher model-estimated risk, then compares the user’s score with people in the AD and non-AD reference groups.

“Higher score means more model-estimated risk of AD. In a large reference dataset, xx% of AD participants and yy% of non-AD participants had scores higher than yours.”
