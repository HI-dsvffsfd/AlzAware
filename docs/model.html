Technical model overview

A data-driven cognitive risk model built for early triage

AlzAware transforms demographic and health-history inputs into a machine-learning risk reference score trained on a large cognitive-health dataset.

The model identifies patterns associated with Alzheimer's disease and translates them into an interpretable comparison against AD and non-AD reference groups.

Technical pipeline

Structured predictors

Age, education, medication count, demographic variables, and self-reported medical history are converted into model-ready features.

XGBoost classifier

A gradient-boosted tree model learns nonlinear risk patterns from processed matrix data and outputs a continuous reference score.

Reference comparison

The score is compared against AD and non-AD score distributions to make the output easier to interpret.

Model performance

Testing performance supports first-step risk triage

After an 80/20 stratified train-test split and 5-fold grid search, the XGBoost model achieved a testing ROC-AUC of 0.8511.

ROC-AUC measures how well the model separates AD and non-AD participants across possible thresholds. A testing AUC above 0.85 suggests strong discrimination for a first-step risk triage tool, while still requiring clinical follow-up for any medical decision.
