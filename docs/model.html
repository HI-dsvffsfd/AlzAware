Model approach

A data-driven cognitive risk model built for early triage

AlzAware transforms demographic and health-history inputs into a machine-learning risk reference score trained on a large cognitive-health dataset. The model is designed to identify patterns associated with Alzheimer’s disease and translate them into an interpretable comparison against AD and non-AD reference groups.

The score is designed to support triage and awareness, not to replace clinical cognitive testing.

Technical pipeline

Structured predictors

Age, education, medication count, demographic variables, and self-reported medical history are converted into model-ready features.

XGBoost classifier

A gradient-boosted tree model learns nonlinear risk patterns from processed matrix data and outputs a continuous reference score.

Reference calibration

The score is contextualized against AD and non-AD score distributions to make the output easier to interpret.

Model performance

A strong AUC supports screening potential

ROC-AUC measures how well a model separates AD and non-AD participants across possible thresholds. A value closer to 1.0 indicates stronger discrimination.

0.89

AlzAware's current XGBoost prototype reaches an approximate testing AUC of 0.89, suggesting strong potential as a first-step risk triage tool.

Final reported values should be updated with the exact training run, confidence interval, and model version used in the final submission.

Score behavior

Reference distributions make the result interpretable

A combined boxplot and violin plot can show how model scores are distributed among AD and non-AD participants in the reference dataset.

This is useful because it communicates both model separation and uncertainty: AD participants tend to receive higher scores, but overlap remains. That is why AlzAware is positioned as risk triage, not diagnosis.
